Current lesson — grammar

A. Place + yǒu + thing (+ ma?) = existence: "there is/are … at place". Pángbiān yǒu fàndiàn ma? · Fùjìn yǒu yí ge fàndiàn. · Xuéxiào pángbiān yǒu kāfēidiàn.
B. A-not-A questions: verb + bu + verb — Nǐ chī bu chī kǎoyú? · Nǐ hē bu hē kāfēi? · yǒu méi yǒu = A-not-A with yǒu: Fùjìn yǒu méi yǒu Zhōngcānguǎn?
C. verb + le ma? = did/has the action happened? — Nǐ kànjiàn nà ge shāngchǎng le ma? · Nǐ chīfàn le ma?
D. zài + place/floor for location — Zài nà ge shāngchǎng sì lóu. · Kāfēidiàn zài shāngchǎng èr lóu. · number + lóu = floor.
E. zài + device + shàng + action = do something on a device — Wǒ zài shǒujī shàng kàn dìtú.
F. verb + yíxià = do briefly/casually — Wǒ zhǎo yíxià. · Wǒ chá yíxià.
G. Distance & duration: duō yuǎn? / chàbuduō + amount / number + gōnglǐ / number + xiǎoshí — Chàbuduō sì gōnglǐ, zǒulù chàbuduō yí ge xiǎoshí.
H. Asking directions: destination + zěnme zǒu? — Qù huǒchēzhàn zěnme zǒu?
